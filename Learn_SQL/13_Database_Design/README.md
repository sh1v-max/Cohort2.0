# Module 13: Database Design

## 📋 What You'll Learn

Master **database design** - how to structure databases properly.

## 🎯 Learning Goals

- ✅ Entity-Relationship (ER) diagrams
- ✅ Database normalization
- ✅ 1NF, 2NF, 3NF concepts
- ✅ Primary and Foreign Keys
- ✅ Design from requirements

## 📚 Topics

1. **Database Design Basics**
   - Tables and relationships
   - Primary keys
   - Foreign keys

2. **Normalization**
   - 1NF (First Normal Form)
   - 2NF (Second Normal Form)
   - 3NF (Third Normal Form)

3. **Relationships**
   - One-to-One
   - One-to-Many
   - Many-to-Many

4. **Real-World Design**
   - From requirements to schema
   - Common patterns
   - Anti-patterns to avoid
