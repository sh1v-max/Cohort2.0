# Interview Preparation

## 📋 What's Here

**SQL interview questions** organized by difficulty.

## 🎯 Purpose

- Prepare for job interviews
- Practice common questions
- Understand patterns
- Gain confidence

## 📚 Question Categories

### Beginner (15 questions)
- Basic SELECT, WHERE, ORDER BY
- CRUD operations
- Aggregate functions
- Simple JOINs

### Intermediate (20 questions)
- Complex JOINs
- Subqueries
- GROUP BY problems
- Real-world scenarios

### Advanced (15 questions)
- Window functions
- CTEs and recursion
- Database design
- Optimization problems

### Company Scenarios (15 questions)
- Google-style questions
- Amazon-style problems
- Meta interview questions
- Real company scenarios

## 🎯 How to Use

1. **Start with Beginner** questions
2. **Solve without hints**
3. **Check solutions**
4. **Move to Intermediate**
5. **Do Advanced problems**
6. **Study Company scenarios**

## 💡 Tips

- Time yourself (15-20 min per question)
- Write clean code
- Explain your approach
- Practice out loud
- Review common patterns

After completing these, you're ready to **ace SQL interviews**!
