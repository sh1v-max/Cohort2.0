## Final Project (End of Week)

**Build a "Dev Dashboard" app** using everything:
- Custom hooks for data fetching, debouncing, local storage
- Tailwind CSS for all styling
- Clean UI following the primitives you learned
- Features: search (debounced), theme toggle (dark/light), bookmarks (localStorage)
