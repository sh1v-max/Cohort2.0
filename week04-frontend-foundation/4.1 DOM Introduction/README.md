# DOM Introduction (4.1)

This folder contains the DOM Introduction exercise for week 4 of the frontend foundation course.

## What we're doing

- Learning how to use JavaScript to read and manipulate the DOM (Document Object Model).
- Selecting elements with `querySelector`, `getElementById`, and similar APIs.
- Changing element content, attributes, and styles with JS.
- Adding event listeners (`click`, `input`, etc.) to make the page interactive.

## Project structure

- `index.html`: sample HTML with elements that we target in JavaScript.
- `style.css`: basic styling for the page (if present in this folder).
- `index.js`: primary script to demonstrate DOM operations and event handling.

## How to run

1. Open `index.html` directly in a browser, or
2. Run a local server in this folder, e.g.:
   - `npx serve` (if installed), or
   - `python -m http.server` (for Python users).

## Learning outcomes

- Understand the DOM tree and how browser renders HTML elements as nodes.
- Learn how to pick DOM elements and update content dynamically.
- Practice connecting UI events to script actions.
- Build confidence using core frontend DOM APIs in vanilla JavaScript.
