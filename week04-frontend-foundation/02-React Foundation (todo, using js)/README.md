# React Foundation (4.2)

This folder contains the React Foundation exercise for week 4 of the frontend foundation course.

## What we're doing

- Building foundational React skills by creating components, JSX, and props.
- Managing state using `useState` and understanding state updates.
- Responding to user events with event handlers (`onClick`, `onChange`, etc.).
- Rendering lists and conditionally showing content in React.
- (To do) adding full-featured UI elements and completing exercises to reinforce concepts.

## Project structure

- `index.html`: entry HTML page that hosts React app.
- `index.js` / `App.js` (or similar): React component code for learning exercises.
- `style.css`: optional styling for components.

## How to run

1. Open `index.html` directly if this is a static React setup.
2. If this folder is part of a React app with npm scripts, run from the project root:
   - `npm install`
   - `npm start`

## Learning outcomes

- Understand how React renders UI declaratively with component trees.
- Practice using hooks (`useState`, `useEffect` as applicable) for interactive behavior.
- Learn to structure reusable components and pass props.
- Gain confidence in core React patterns before building full apps.
