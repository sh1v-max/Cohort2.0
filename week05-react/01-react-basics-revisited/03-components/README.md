# React Components

## What is a Component?
Components are the building blocks of any React application.
A component is essentially a JavaScript function that returns React elements (JSX) telling React what should be rendered on the screen.

Components let you split the UI into independent, reusable pieces, and think about each piece in isolation.

## Key Properties:
1. **Reusability**: You can use a single component multiple times across your app (e.g., a `Button` component).
2. **Readability**: Components break complex UIs into small, manageable chunks.
3. **Props (Properties)**: Components can accept inputs called **props**, which allow you to pass dynamic data down to child components.
