# Static vs Dynamic Websites

This folder contains a basic explanation of Static vs Dynamic websites.

## 1. Static Websites

A **Static Website** delivers exactly the same content to all visitors. The content is "hardcoded" into HTML files.

- **Key Characteristics**: Does not connect to a database, no changing content (unless manually updated by a developer), and does not respond to user interactions dynamically.
- **Example**: A simple portfolio website or an informational "About Us" page.
- **File to explore**: `static-website.html`

## 2. Dynamic Websites

A **Dynamic Website** generates content on the fly or updates the view based on user interactions and data fetching.

- **Key Characteristics**: Content can change based on the user (e.g., logging in), interacts with APIs or databases, and the DOM is updated in real-time using JavaScript (and libraries like React).
- **Example**: Facebook, X (formerly Twitter), or a simple To-Do application where you can add/remove items interactively.
- **File to explore**: `dynamic-website.html`

## Why learn this?

To understand React, you must first understand the problem it solves. Dynamic websites require constant updating of the DOM (Document Object Model) when state/data changes. React simplifies DOM manipulation by doing it efficiently under the hood.
